# Release notes

## 0.1.2 — standalone publication

- Guided near-left / near-right / far-edge desktop measurement and outline confirmation.
- Six approximate-life-size accessory types, eight placements and move/turn/remove/cancel editing.
- Live spatial anchors, rotated footprint bounds and virtual-object overlap feedback.
- Off/hard/soft occlusion, manual lighting, transparent desktop shadows and movable controls.
- Explicit **session-only** lifetime. Optional persistence was removed after repeated package-trust failures; it is not claimed to be fixed.

This release publishes the existing Quest-tested **0.1.2 (3)** APK unchanged. New repository branding does not imply a new binary or another device test. See [BUILDING.md](BUILDING.md) for its checksum and limits.
